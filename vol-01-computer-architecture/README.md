# Volume 1 — Computer Architecture for Backend Engineers

How the machine actually executes your backend code: CPUs, the memory hierarchy, storage,
NUMA, and the mechanical sympathy that separates fast systems from slow ones. Aimed at senior
backend engineers who want to reason about performance from first principles.
