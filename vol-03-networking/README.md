# Volume 3 — Networking for Backend Engineers

The network as a backend engineer must understand it: the path of a packet, TCP and QUIC,
DNS, TLS, the HTTP family, gRPC, load balancing, proxies and service mesh, and the reliability
patterns (timeouts, retries, hedging) that keep distributed calls sane.
