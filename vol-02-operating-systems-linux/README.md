# Volume 2 — Operating Systems and Linux

The operating system as it actually behaves under a high-throughput backend service:
processes and scheduling, virtual memory, the system-call boundary, file systems, the Linux
I/O models, namespaces and cgroups, the network stack, and the performance tools (perf, eBPF)
that let you see all of it.
